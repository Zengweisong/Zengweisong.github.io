01 / PROBLEM

要解决的问题

通用笔记很难支持组数、重量和计时，传统健身应用又常被社交和内容功能挤占，记录一次训练需要太多步骤。

02 / APPROACH

采用的方向

计划提供默认路径，但临时加组和换动作不能破坏历史记录。

03 / OUTCOME

已经做到

已完成动作、组数和计时三个训练现场的核心模块原型。

01 / OVERVIEW

项目全貌

一个强调训练现场效率的记录工具，让计划、动作、组数和休息计时自然串联，而不是在健身房里操作复杂表格。

WORK SCOPE
  • 训练计划
  • 动作管理
  • 组数记录
  • 休息计时

02 / CHALLENGE

挑战与解法

THE CHALLENGE

遇到的问题

训练计划需要结构化，但临时加组、换动作又必须足够自由。

THE RESPONSE

如何解决

让计划提供默认路径，同时允许用户在训练中即时调整且不破坏历史数据。
