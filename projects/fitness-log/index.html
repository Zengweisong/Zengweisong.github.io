01 / OVERVIEW

项目简介

一个强调训练现场效率的记录工具，让计划、动作、组数和休息计时自然串联，而不是在健身房里操作复杂表格。

02 / MOTIVATION

为什么做

通用笔记很难支持组数、重量和计时，传统健身应用又常被社交和内容功能挤占，记录一次训练需要太多步骤。

03 / FEATURES

核心功能

  • ✓周期训练计划与动作库
  • ✓训练记录和组数追踪
  • ✓组间休息计时
  • ✓自由训练与历史回顾

05 / PROCESS

开发过程

01

最初想法

从组间休息时最短的操作路径出发，减少每次记录需要点击的次数。

02

第一版

先完成动作、组数和计时三个训练现场最常用的模块。

03

遇到的问题

训练计划需要结构化，但临时加组、换动作又必须足够自由。

04

如何解决

让计划提供默认路径，同时允许用户在训练中即时调整且不破坏历史数据。

05

后续计划

增加训练趋势、个人纪录和离线同步，继续压缩现场操作成本。
